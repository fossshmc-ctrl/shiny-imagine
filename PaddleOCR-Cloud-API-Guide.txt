PaddleOCR 云端 API 配置与发放说明 · V26
========================================

1. 在图片微调的 OCR 配置中填写有效 Access Token。
2. 令牌只用于调用 PaddleOCR 官方托管异步 API。
3. 发布包不包含 PaddleOCR 模型权重，也不包含用户令牌。
4. 结果下载支持重定向、代理失败后直连和下载诊断。
5. 如出现上游超时或鉴权失败，请优先检查网络、令牌有效期和官方服务状态。

V26 队列繁忙处理
------------------
- 官方创建任务返回 HTTP 400 且 JSON code=10010 时，V26 识别为临时 queue_busy。
- 默认自动重试 4 次：3 秒、6 秒、12 秒、20 秒，并增加少量随机抖动。
- 本地 Node/Python 服务会对创建 job 阶段做 FIFO 串行化，避免多个标签页同时提交。
- 前端可通过 /api/paddleocr-cloud/queue-status?requestId=... 查看当前排队/重试/已提交状态。
- 401/403 不重试；其他参数型 HTTP 400 不重试；429/部分 5xx/临时网络错误会有限重试。
