V27.8 CHANGELOG
===============

版本：V27.8 / 27.8.0
Build：v27.8-region-prompt-bridge-stability-20260814
发布日期：2026-08-14

修复：混合区域 Prompt 丢失
--------------------------
- 修复 V27.7 在任意区域出现人工文案指令后，整体切换到人工指令数组、从而丢弃其他自动区域指令的问题。
- Prompt 合并改为按任务逐项解析：user -> effective -> fallback -> generated-default。
- 每一个已选区域都会在“最高优先级：AI 修改指令”中拥有独立条目。
- 结构化任务 JSON 新增 `prompt_source`，用于定位指令来源。
- 最终 Prompt 新增强约束：每个已选区域都必须执行，不得因一个人工文案要求忽略其他自动区域或自由添加区域。

修复：自由添加区域无法正常生成
------------------------------
- 新建自由区域时写入明确的 `freeInstruction`。
- 将自由区域初始指令写入 `__v173ManualRequirement`。
- 新增旧自由区域自动迁移：manual-free-region / manual-brush / custom_*。
- 即使自由区域没有历史 Prompt，也会生成默认区域执行指令。
- `manualCreated` 与 `manual-free-region` 纳入“保留人工区域”识别策略，避免重新识别后自由区域丢失。

修复：草稿显示已修改但生成仍读取旧值
------------------------------------
- 点击微调生成前自动提交当前区域文案草稿。
- 同时自动提交“识别文案纠正”中的活动文档块草稿。
- 草稿提交发生在 AI 修改指令与区域任务同步之前。
- 切换区域、关闭工作台时保存当前区域文案，避免未失焦内容丢失。

诊断与兼容
----------
- 回归桥接结果保留 `missingInstructionRegionIds`，可精确显示缺失区域。
- 回归匹配器会还原结构化 JSON 中的 `\n`、Unicode 和转义引号，避免把已进入任务 JSON 的自动指令误判为缺失。
- 新增 `RegionAiPromptV278` 与 `RegionPromptStateV278`，同时保留 V27.3/V27.1/V27.7 兼容别名。
- 保留旧项目的文字原文、人工要求和实时参数字段，不进行破坏性迁移。
- HTML 与 Windows 启动器缓存版本更新为 27.8，防止浏览器继续加载 V27.7 Prompt 模块。

安全边界
--------
- 回归前检仍发生在参考图压缩、上传和 EvoLink 任务提交之前。
- 本地 Prompt 桥接失败不会提交计费生图任务。
- 本次开发和验证未调用外部计费生图 API，也未生成图片。
