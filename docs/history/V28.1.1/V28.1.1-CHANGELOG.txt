AI 图灵线框工作台 V28.1.1 Windows
================================

版本：V28.1.1
Build：v28.1.1-performance-panel-collapse-20260814
发布日期：2026-08-14

本版本针对智能区域编辑工作台的“点击到出图性能仪表”做 UI 收敛，不改变微调生图链路、Prompt 组成、区域识别和任务计费逻辑。

核心更新
1. 将“点击到出图性能仪表”改为单行横向折叠按钮。
2. 默认收起，释放右侧生成结果区域的垂直空间。
3. 展开后完整保留 9 个性能阶段、EvoLink task 生命周期、轮询恢复信息和诊断结论。
4. 点击按钮只切换当前仪表详情的显示状态，不重新生成图片、不重新提交任务。
5. 折叠状态使用 localStorage 持久化，刷新页面后保持用户最后选择。
6. 增加键盘焦点样式和 aria-expanded / hidden 状态，便于可访问操作。
7. 发布缓存参数统一升级为 ?v=28.1.1，Windows 启动器与 /api/health 使用同一 Build ID。

明确不变
- 不修改实际生图 Prompt。
- 不修改 EvoLink 请求参数。
- 不修改微调任务 task_id 恢复逻辑。
- 本版本制作过程未调用真实生图接口。

验证
- Node.js 测试：219 / 219 通过。
- 性能仪表新增专项回归测试。
