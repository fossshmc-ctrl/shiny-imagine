V27.3.2 CHANGELOG
Date: 2026-08-13
Base: V27.3.1 micro-performance Windows package

1. 智能区域微调结果 UI 下移
- 原实现：v225-output-caption 使用 position:absolute + bottom:10px，覆盖在生成图底部。
- 新实现：结果容器改为纵向 flex；图片在上、结果信息/操作栏在下。
- v225-output-caption 改为 position:static，成为正常文档流的一部分，不再遮挡任何生成图像素。
- 图片保留 zoom-in 点击预览；结果底栏使用默认指针，避免误导。

2. 结果底栏新增图片下载
- 新增“↓ 下载图片”按钮，只针对当前智能区域微调结果。
- 优先调用现有 openImageDownloadDialog，复用明确确认式 JPG/JPEG/PNG/PDF 导出流程。
- 若主下载弹窗模块不可用，回退到 window.ImageExport.requestDownloadTarget + exportImageToTarget。
- 缺少结果图或导出模块异常时，给出明确状态提示，不执行空下载。
- 下载按钮事件先于图片预览处理并阻止冒泡，避免点击下载时同时打开大图预览。

3. 底栏布局与小屏适配
- 信息区与操作区拆分为 v232-output-info / v232-output-actions。
- 大屏横向排列；窄屏（<=820px）改为纵向布局。
- 长结果名采用 ellipsis；元信息在小屏隐藏，优先保证操作按钮可用。
- 回归检测按钮与下载按钮统一 28px 最小高度并保持不换行。

4. Windows 版本一致性修复
- 页面标题、静态资源 cache query、server.js/server.py health version、buildId、start.bat 期望版本统一为 V27.3.2。
- config.json / package.json / copy-coze.private.json 的当前版本元数据同步升级。
- start.bat 的窗口标题、就绪检查、缓存击穿 URL 同步升级，避免 V27.3.2 启动后被旧 V27.3.1 条件误判为不匹配。

5. 兼容性策略
- micro-adjust-v27.3.1 仍作为微调协议通道标识保留，这是协议兼容标识，不是当前应用版本。
- 底层 V27.3.1 性能模块版本常量保持不变，避免为纯 UI/下载修复引入网络/计费链路回归。
- 不增加自动重试计费 generation POST。

6. 测试
- 新增 V27.3.2 输出底栏/下载静态回归测试。
- 更新微调通道测试对当前 UI stage 标签的 V27.3.2 预期。
- 完整 Node 测试、Python fallback 测试及运行时 health 在发布前执行。
