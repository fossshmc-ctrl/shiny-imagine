V28.0 CHANGELOG
================
日期：2026-08-14

一、BUG 1：AI 修改指令偶发不生效 / 返回近似原图
------------------------------------------------
- 将“文字编辑”从普通自然语言提示提升为独立的确定性编辑约束。
- Prompt 增加【文字内容强制执行｜V28.0】。
- 明确要求新文案逐字执行，禁止同义替换、翻译、漏字、增字和自动润色。
- 对已编辑文字区域生成独立高清裁剪参考图，随 source / layout-mask-guide 一起进入微调参考图集合。
- 回归前检查新增文字任务校验：如果文字任务未进入 V28.0 文字强制段，则阻止提交计费任务。
- 保留原有 AI 修改指令、区域 ID、source/target 几何和 Mask 回归保护。
- 不自动重复提交计费任务，避免因本地检测失败造成重复扣费。

二、BUG 2：第二次微调是否继承第一次结果
----------------------------------------
诊断结论：底层行为原本就是“确认结果后作为当前底图”，属于连续微调设计，而不是随机串图。
V28.0 不删除这个能力，而是把它显式化并提供独立选择：
- 当前结果：继续在上一轮确认结果上修改，保留上一轮已完成内容。
- 识别原图：从本次识别得到的原始图片重新开始，不继承上一轮已确认结果。
- 默认仍为“当前结果”，保持连续微调工作流兼容。
- 每次点击生成仍创建独立 generation/session，旧一轮的 generating/result 状态不会污染新一轮。
- 基图模式写入项目状态，并随项目保存/恢复。
